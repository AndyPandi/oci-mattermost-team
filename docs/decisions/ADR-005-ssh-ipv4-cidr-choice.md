# ADR-005: SSH IPv4 CIDR 전체 범위 선택

- 날짜: 2026-11-14
- 상태: Accepted

## 배경
사용자가 설치 입력에서 `0.0.0.0/0` 허용을 명시적으로 요청했다.

## 결정
- 기존 구현의 SSH `/24–/32` 제한 및 `/0` 거부 결정을 이 ADR로 대체한다. 과거 ADR·journal은 당시 기록으로 보존한다.
- Terraform과 RM 입력은 유효한 IPv4 CIDR `/0–/32`를 허용하고 IPv6·잘못된 입력은 거부한다. 별도 opt-in gate는 두지 않는다.
- 필수 입력·기본값 없음과 관리자 공인 IP `/32` 권장을 유지한다. 테스트의 `/32` 예시도 유지한다.
- `0.0.0.0/0`은 TCP 22를 모든 IPv4에 허용하며 SSH 키 인증은 여전히 필요하다. 설치 후 자동으로 닫히지 않는다. 운영자가 스택 변수 `ssh_ingress_cidr`를 좁히고 Plan 검토 후 Apply한다. 기존 네트워크의 합산 허용 규칙도 별도로 검토한다.
- 다른 포트, 인증, 이미지와 live OCI 자원은 변경하지 않는다.

## 고려한 대안
기존 제한 또는 추가 확인 gate는 명시적인 입력 선택 요청과 맞지 않아 채택하지 않는다. 세계 공개를 기본값으로 지정하지 않는다.

## 결과
설치 시 모든 IPv4 원본을 선택할 수 있지만 인터넷 경로가 있는 VM의 SSH 스캔·접속 시도 노출이 커진다. `/32` 사용 및 설치 후 범위 축소를 권장하며 실제 Console UI와 OCI 적용은 이 로컬 검증의 범위 밖이다.
