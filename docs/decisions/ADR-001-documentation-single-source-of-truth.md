# ADR-001: 문서 Single Source of Truth

날짜: 2026-11-12

상태: Accepted

## 배경

이 프로젝트에는 사람과 AI 에이전트가 함께 따를 수 있는 반복 가능한 문서 구조가 필요합니다.
문서 역할이 명확하지 않으면 현재 상태, 아키텍처 설명, 의사결정, 작업 이력이 서로 섞이거나 중복될 수 있습니다.

## 결정

docs 기반 Single Source of Truth 문서 체계를 사용합니다.

- `docs/project-state.md`는 현재 상태의 유일한 source of truth입니다.
- `docs/README.md`는 문서 헌법을 정의합니다.
- `docs/architecture/*`는 현재 시스템 동작과 구조를 설명합니다.
- `docs/decisions/ADR-XXX-*.md`는 중요한 결정을 기록합니다.
- `docs/journal/YYYY-MM.md`는 완료된 작업 이력을 기록합니다.
- `AGENTS.md`는 AI 에이전트가 이 구조를 읽고 유지하도록 지시합니다.

## 고려한 대안

1. 모든 메모를 `README.md`에 둡니다.
2. 고정된 역할 없이 임시 문서를 계속 사용합니다.
3. 이슈 트래커 이력을 주요 프로젝트 메모리로 사용합니다.

## 결과

### 긍정적 영향

- 현재 프로젝트 사실을 확인할 위치가 명확해집니다.
- 아키텍처, 결정, 이력이 분리됩니다.
- AI 에이전트가 문서를 읽고 갱신하는 기준이 안정됩니다.

### 부정적 영향

- 프로젝트 상태를 바꾸는 작업에는 문서 갱신이 필요합니다.
- 기존 프로젝트는 한 번의 문서 정리가 필요할 수 있습니다.
